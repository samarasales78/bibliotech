# BiblioTech

O **BiblioTech** é um sistema de gerenciamento de biblioteca desenvolvido em **Java** como projeto acadêmico das disciplinas de **Modelagem e Análise de Sistemas** e **Programação Orientada a Objetos**.

## Funcionalidades

* Cadastro de usuários e livros
* Login de usuários
* Empréstimo e devolução de livros
* Listagem de livros disponíveis
* Persistência de dados em arquivos CSV

## Tecnologias

* Java
* Programação Orientada a Objetos
* Arquivos CSV

## Como executar

1. Clone o repositório.
2. Abra o projeto em uma IDE Java (Eclipse, IntelliJ ou VS Code).
3. Execute a classe `Main.java`.
